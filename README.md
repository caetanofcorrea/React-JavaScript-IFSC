📘 Curso Frontend com a Biblioteca React e Javascript — IFSC

Este repositório reúne todos os exercícios, atividades e projetos desenvolvidos durante o módulo de React e JavaScript do curso de Desenvolvimento de Sistemas do IFSC.
O objetivo é registrar minha evolução no front-end e consolidar os principais fundamentos da programação web moderna.

🚀 Tecnologias Utilizadas

JavaScript ES6+

React

Vite ou Create React App (dependendo do projeto)

Node.js

HTML5 & CSS3

React Router

Hooks (useState, useEffect, useContext)

APIs REST
